# 🛒 E-Commerce React Practice

A beginner-friendly e-commerce website built with React and Vite.

This project was created to practice React fundamentals while building a realistic e-commerce application.

## 🚀 Live Demo

[View the live website] https://ecommerce-react-practice.vercel.app/

## 🛠️ Built With

- React
- JavaScript
- Vite
- React Router
- React Hook Form
- CSS
- LocalStorage

## ✨ Features

- Product listing
- Product details
- Add products to cart
- Shopping cart
- Checkout page
- User signup and login
- Logout functionality
- Authentication using React Context
- Form validation
- LocalStorage

## 🧠 What I Learned

Through this project, I practiced:

- React components
- Props
- `useState`
- `useContext`
- React Router
- `useParams`
- React Hook Form
- Array methods such as `find`, `map`, and `filter`
- Conditional rendering
- LocalStorage
- Git and GitHub
- Deploying a React application with Vercel
